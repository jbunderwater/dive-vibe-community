## Sardine Run Reef

This entry represents the reef diving grounds off Port St Johns on the Wild Coast, where South Africa's annual sardine run is watched and dived each year.

## Overview

This site represents the reef diving grounds off Port St Johns on the Wild Coast, where the continental shelf comes closer to shore than anywhere else on South Africa's east coast — a key reason the annual sardine run is so accessible to divers here. The run itself is really a predator migration: sardines move up the coast in dense baitballs, and divers and snorkellers in the water encounter common dolphins, Cape gannets diving from above, and sharks and whales moving through in pursuit, rather than the sardines being the main draw. Dives here run roughly 8–20 metres depending on where the action is on a given day. The run is centred on June and July, though its timing and intensity vary year to year and cannot be guaranteed. This is not a single fixed reef with a formal name in dive-site listings — it's a stretch of Wild Coast reef used as the base for sardine-run diving, so treat it as representing that area rather than one specific charted site.

## Site Information

- **Location**: Off Port St Johns, Wild Coast, South Africa
- **Entry Type**: Boat dive
- **Site Type**: Reef
- **Difficulty Level**: Advanced
- **Maximum Depth**: 20 meters
- **Best Time**: June-July (sardine run), though exact timing varies annually

## Marine Life

Confirmed for the sardine run at Port St Johns: common dolphins, Cape gannets, and predatory sharks and whales following the baitballs (species mix varies by day and is not consistently itemised by source). No source consulted for this QA pass named specific reef-resident species for a fixed "Sardine Run Reef" location, so no permanent reef fish list is given here — species seen depend heavily on whether the run is active.
