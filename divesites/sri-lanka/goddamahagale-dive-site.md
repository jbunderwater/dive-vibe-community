## Goddamahagale dive site

An offshore reef/rock site on Sri Lanka's west coast roughly 7 km off Negombo — not, as a prior draft of this page claimed, near Kalutara/Beruwala/Bentota, which are 75-90 km further south.

## Overview

This site's coordinates (7.2365°N, 79.7824°E) place it about 7 km offshore, west-northwest of Negombo town (7.2083°N, 79.8358°E) — squarely within the area Negombo dive operators describe, not near Kalutara, Beruwala, or Bentota, which sit 75-90 km to the south near Colombo. The name "Goddamahagale" closely resembles "Goda Maha Gala," a dive site named by several Negombo-area operator listings, but those listings give only generic, repeated boilerplate ("intricate cave systems") without confirming details, and a third-party dive-site database gives coordinates for a site called "Maha Gala" about 7.6 km north of this one (7.305°N, 79.784°E) — close enough to be regionally consistent but too far to confidently call it the same site. Given that gap, this write-up treats the Negombo-area identification as likely but unconfirmed rather than certain. Negombo-area sites in general are boat dives several kilometers offshore, which conflicts with this database's current "shore entry" tag for this site; that should be reviewed. The prior write-up's specific claims (hard corals, sea fans, lionfish, scorpionfish, wrasse, reliable turtles and reef octopus) could not be traced to any source discussing this site and have been removed.
