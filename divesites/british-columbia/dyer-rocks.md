# Dyer Rocks

A shore-accessible rocky reef on Ardmore Drive in Saanich Inlet, near Victoria.

## Overview

Dyer Rocks is a shore dive site on Ardmore Drive in the Saanich Inlet area near Victoria, listed by name in ScubaBC's regional dive-site directory. A previous version of this page described Dyer Rocks as boat-only; site listings identify it as a shore-accessible location, and this page has been corrected accordingly.
